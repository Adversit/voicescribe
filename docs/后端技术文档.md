# VoiceScribe 后端技术文档

更新时间：2026-02-23  
核心文件：`backend/server.py`

## 1. 技术栈
- Python 3.10+
- FastAPI + Uvicorn
- ASR 引擎适配层：
- `backend/engines/whisper_engine.py`
- `backend/engines/whispercpp_engine.py`
- `backend/engines/funasr_engine.py`
- `backend/engines/parakeet_engine.py`
- 说话人模块：`backend/diarization/speaker.py`
- 文本后处理：`backend/postprocess/ai_refiner.py`

## 2. 进程与启动
入口为 `server.py` 的 `main()`：
- 默认监听 `127.0.0.1:8765`
- 支持参数：
- `--mock`：强制 Mock 模式
- `--host`
- `--port`

自动判定 Mock 模式逻辑：
- 若四类 ASR 引擎都不可用，则自动进入 Mock 模式。

## 3. 引擎可用性探测
启动时探测：
- Whisper：检查 `faster_whisper` 或 `whisper` 模块
- Whisper.cpp：检查 `whisper-cli` 与本地模型文件
- FunASR：检查 `funasr` 模块
- Parakeet：检查 `nemo`/`nemo_toolkit`

## 4. 全局状态与缓存
- `engines`：已加载引擎实例与当前模型
- `diarizer`：说话人标注实例（懒加载）
- `model_downloads`：模型下载状态（内存）
- `MODEL_CACHE_DIR`：
- 优先读取环境变量 `VOICESCRIBE_MODEL_DIR`
- 否则按平台使用默认目录
- `voicescribe_models.json`：模型注册表（路径、大小、更新时间）

## 5. 预加载机制
- 环境变量 `VOICESCRIBE_PRELOAD_MODELS=1` 时，启动时执行预加载。
- 当前预加载配置默认包含 FunASR `seaco-paraformer`。

## 6. 说话人模块设计
`SpeakerDiarizer` 主要能力：
- 加载说话人识别/分离模型（FunASR）
- 注册说话人（保存 embedding）
- 删除说话人
- 列表查询
- 将 diarization 结果映射回转写分段并合并文本

默认说话人数据目录：
- `~/.voicescribe/speakers`

## 7. AI 文本优化模块
`AIRefiner` 主要逻辑：
- 使用本地配置 prompt（`~/.voicescribe/refine_prompt.txt`）
- 在检测到英文样式片段且存在热词时，调用 Claude CLI 做热词纠错替换
- 异常时回退原始文本

说明：
- 该功能依赖本机 `claude` 命令可执行和可用模型。

## 8. 错误处理策略
- API 层使用 `HTTPException` 返回业务错误。
- 引擎或依赖不可用时返回 400/404 等明确错误。
- 文件上传场景使用临时文件并在 `finally` 中清理。
- WebSocket 异常通过 `type=error` 消息返回后关闭连接。

## 9. 与 Electron 主进程交互
Electron 主进程通过 `frontend/electron/backend.ts` 调用 HTTP API，核心调用链：
- Renderer 录音 -> 主进程落地临时 WAV -> 后端 `/transcribe` -> 主进程分发结果到前端 UI 与历史记录。
