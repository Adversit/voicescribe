# VoiceScribe 功能文档

更新时间：2026-02-23  
范围：当前 `frontend/electron` + `frontend/src` + `backend/server.py` 实现

## 1. 产品概述
VoiceScribe 是一个基于 Electron + Next.js + FastAPI 的桌面语音转写工具，支持全局快捷键录音、悬浮录音状态、后端 ASR 转写、文本输出和历史记录管理。

## 2. 核心功能
1. 全局快捷键录音
- 通过 Electron `globalShortcut` 注册快捷键。
- 触发后开始录音，再次触发停止录音并进入转写状态。

2. 托盘常驻与悬浮窗
- 应用关闭主窗口后驻留系统托盘。
- 录音时显示 overlay 悬浮窗，实时展示录音状态与音量波形。

3. 语音转写
- 录音音频在前端编码为 WAV（16kHz、单声道、PCM16）。
- 主进程将音频发送给后端 `/transcribe` 接口。
- 支持引擎/模型/语言、热词、说话人标注、AI 文本优化等参数。

4. 输出模式
- `clipboard`：仅复制到剪贴板。
- `directInput`：尝试自动粘贴到当前应用（Windows 下优先使用 `robotjs`，失败回退 PowerShell SendKeys）。
- `both`：剪贴板 + 自动粘贴。

5. 历史记录
- 使用 Zustand 持久化保存历史转写内容。
- 支持搜索、编辑、删除、清空。
- 支持导出单条记录为 `TXT` 或 `Markdown`。

6. 热词词表
- 在设置页维护热词列表（新增、删除、清空）。
- 转写时作为 `hotwords` 传给后端。

7. 说话人管理
- 支持录制声纹并注册说话人。
- 支持查询和删除已注册说话人。

8. ASR 引擎与模型管理
- 支持引擎列表查询、模型加载。
- FunASR 模型支持下载/删除/状态轮询。

## 3. 设置页功能模块
当前设置导航包含：
- 通用设置（语言、输出模式、说话人标注开关、AI 优化开关、后端健康状态）
- 引擎设置（引擎与模型选择、模型下载/删除/加载）
- 词表设置（热词管理）
- 说话人设置（声纹录制与管理）
- 快捷键设置（组合键与按键）
- 历史设置（历史列表管理与导出）

## 4. 后端能力（用户可感知）
- 支持 `whisper`、`whispercpp`、`funasr`、`parakeet`（可用性取决于环境安装）。
- 支持 Mock 模式，在无 ASR 依赖时可返回模拟结果。
- 支持健康检查、引擎/模型管理、说话人管理、流式转写 WebSocket。

## 5. 使用流程（典型）
1. 打开应用并在设置中选择引擎、模型、语言和输出模式。  
2. 按快捷键开始录音。  
3. 再按一次快捷键停止录音并自动转写。  
4. 结果按输出模式写入剪贴板或直接粘贴。  
5. 转写结果自动进入历史记录，可继续编辑、导出或删除。  

## 6. 运行与发布（简要）
- 开发：`frontend` 使用 `npm run dev:electron`。
- 后端：`backend/server.py`（默认 `127.0.0.1:8765`）。
- Windows 脚本位于 `scripts/windows`（安装、开发、打包、测试）。
