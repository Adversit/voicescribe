# VoiceScribe 功能文档

更新时间：2026-03-15  
范围：当前 `frontend/electron`、`frontend/src`、`backend/server.py`、`backend/meeting/*` 的已落地实现

## 1. 产品概述

VoiceScribe 是一个基于 Electron + React + FastAPI 的桌面端语音转录工具，当前重点支持：
- 文件上传转录
- 流式实时转录
- 说话人注册与识别
- AI 文本优化与会议摘要
- 历史记录与导出

## 2. 核心功能

### 2.1 文件上传转录

- 前端录音或选择音频文件后，调用 `POST /transcribe`
- 支持配置引擎、模型、语言、热词、说话人识别、AI refine
- 返回完整文本、segments、时长、引擎和模型信息

### 2.2 流式实时转录

- 前端实时采集 PCM 音频并连接 `WS /stream`
- 后端使用 VAD 检测语句边界
- 每段音频触发 ASR、speaker 分析和摘要更新
- 前端实时显示 utterance、活跃 speaker、摘要

### 2.3 说话人管理

- 支持录制样本并注册说话人
- 支持查看、删除已注册说话人
- 注册接口走声纹模型链路，默认以 CAM++ 为主

### 2.4 流式说话人识别

当前处理链路：
- `ASR -> pyannote clustering -> CAM++ mapping`

当前支持：
- 主 speaker
- 候选 speaker 列表 `speakers`
- 段内时间子段 `speaker_spans`
- 疑似重叠标记 `overlap_detected`
- VAD 内先后 speaker 的切段重转写

### 2.5 AI 文本优化与摘要

- 单句 refine
- 周期性会议摘要
- 决策项提取
- 待办项提取

### 2.6 历史记录

- 流式会话结束后自动写入历史
- 支持编辑、删除、清空
- 支持 speaker 过滤
- 支持带 speaker / 摘要 / 完整信息导出

## 3. 设置页功能模块

当前设置导航包括：
- `live-transcript`
- `general`
- `engine`
- `vocabulary`
- `speaker`
- `hotkey`
- `history`

关键设置项包括：
- `enableStreaming`
- `enableDiarization`
- `enableAiRefine`
- `meetingOutputFormat`
- `speakerModel`
- 热词与快捷键

## 4. 当前说话人能力说明

### 4.1 注册

- 注册使用 `SpeakerDiarizer`
- 默认依赖 CAM++ 体系提取声纹

### 4.2 流式分群与映射

- 分群优先使用 `pyannote/embedding`
- 映射优先使用 CAM++（FunASR）
- 若映射后端不可用，才退回 `pyannote` fallback

### 4.3 当前已解决的问题

- 项目级模型路径优先
- 引擎页加载模型时联动 preload speaker backends
- 一个 VAD 段内的多 speaker 先后切分
- 对所有 speaker 的防裂变收紧策略

### 4.4 当前未解决的问题

- 同一时间点多人同时说话的精确文本归属
- 词级 speaker 对齐

## 5. 模型管理

- 支持模型状态查看、下载、删除、加载
- 引擎页“加载模型”不只加载 ASR，也会按设置重载 speaker backends
- 项目运行优先使用 `models/` 目录下的本地缓存

## 6. 典型使用流程

1. 在设置页选择引擎、模型和 speaker model。  
2. 如需实名映射，先注册说话人。  
3. 开启流式转录，前端连接 `WS /stream`。  
4. 后端输出 utterance、speaker_active、summary。  
5. 会话结束后自动写入历史，按需要导出。
