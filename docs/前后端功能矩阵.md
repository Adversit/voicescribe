更新时间：2026-02-23  
判定口径：以当前代码实现为准（`frontend/src`、`frontend/electron`、`backend/server.py`）

状态说明：
- `已实现`：该层有明确实现
- `部分实现`：有实现但能力不完整或受条件限制
- `未实现`：该层没有对应实现
- `已打通`：前后端链路可直接工作
- `部分打通`：能跑通但存在类型/能力缺口
- `未打通`：有一侧无实现或未接线

## 关键结论
1. 当前不存在“前端已调用但后端完全缺失”的核心 API 断点。  
2. 主要缺口是 `WS /stream`：后端已有，前端主 UI 未形成稳定可用入口。  
3. `AI 优化` 和 `直接输入` 都属于“有实现但依赖环境”的部分打通能力。
