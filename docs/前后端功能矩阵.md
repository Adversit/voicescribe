## 关键结论

1. 旧版“前端未接通稳定流式入口”的结论已经失效，当前主 UI 已完整接入 `WS /stream`。  
2. 当前 speaker 体系已经不是“单 speaker utterance”，而是支持 `speakers + speaker_spans + overlap` 的结构。  
3. 当前系统已能处理“一个 VAD 内先后不同 speaker”，但还不能处理“同一时间点多人同时说话的精确文本归属”。
