# VoiceScribe 功能总览

> 最后更新：2026-03-11

## 一句话定位

桌面端语音转文字工具，支持快捷键速记和会议录制两种模式，集成多 ASR 引擎、说话人识别和 AI 后处理。

---

## 模式一：快捷键速记

按下全局热键（默认 Alt+R）开始录音，松开后自动转录。适合即时记录想法、输入文字。

| 功能 | 说明 |
|------|------|
| 全局热键 | 可自定义修饰键（Ctrl/Alt/Shift/Win）+ 字母/数字键 |
| 浮窗显示 | 录音时显示透明悬浮窗，含波形动画和时长 |
| 实时流式 | 可选，录音中即时返回部分结果 |
| 输出方式 | 复制到剪贴板 / 直接输入到当前应用 / 两者兼有 |
| 历史记录 | 自动保存转录结果，可搜索、编辑、导出 |

---

## 模式二：会议录制

手动开始/停止，支持长时间录制，带完整的会议处理流水线。

| 功能 | 说明 |
|------|------|
| 实时转录 | WebSocket 持续推送识别结果 |
| 说话人识别 | 自动区分不同说话人，颜色标注 |
| AI 文本优化 | 去除语气词、修正错别字、术语纠正 |
| 增量摘要 | 每 N 秒（可配置 60-300s）自动生成会议纪要 |
| 决策/待办提取 | 从对话中提取决策事项和行动项 |
| 导出 | Markdown 格式（含摘要、决策、待办、完整文稿） |
| 说话人筛选 | 按说话人过滤查看发言内容 |

**会议处理流水线：**
```
麦克风音频 → VAD 语音检测 → 说话人跟踪 → ASR 转录 → AI 润色 → 增量摘要
```

## ASR 引擎

支持 5 种引擎，可在设置中切换：

| 引擎 | 语言优势 | 特色 | GPU 要求 |
|------|---------|------|---------|
| **FireRed** ⭐ | 中文最优 (CER 3.18%) | 1.1B 参数 AED 模型 | 推荐 GPU |
| **FunASR** | 中文 | 热词增强、内置 VAD 和标点 | 可选 |
| **Whisper** | 多语言 | faster-whisper 加速，多模型尺寸 | 可选 |
| **Whisper.cpp** | 多语言 | 量化模型，资源占用低 | 不需要 |
| **Parakeet** | 英文 | NVIDIA NeMo 方案 | 必须 NVIDIA |

**模型管理：** 可在设置中下载/删除模型，支持进度显示。

## 说话人识别

| 功能 | 说明 |
|------|------|
| 声纹注册 | 上传 5-10 秒语音样本注册说话人 |
| 实时识别 | 会议中自动匹配已注册声纹 |
| 管理 | 查看/删除已注册说话人 |
| 底层模型 | FunASR CAM++ (注册) + diart/pyannote (实时跟踪) |

---

## AI 后处理

### 文本润色
- 去除语气词（嗯、啊、那个…）
- 修正错别字和语法
- 术语纠正（基于自定义热词表）

### 会议摘要
- 3-5 句话概要
- 决策事项列表
- 行动项（含负责人）

### LLM 提供者
| 提供者 | 说明 |
|--------|------|
| Claude CLI | 默认，无需 API Key |
| Anthropic API | 直接 SDK 调用 |
| 自定义 API | 支持配置 URL 和 Key |

## 设置项汇总

| 分类 | 设置项 |
|------|--------|
| **通用** | 语言（中/英/日/自动）、输出方式、流式转录开关 |
| **引擎** | 引擎选择、模型选择、模型下载管理 |
| **热词** | 自定义术语表，用于提升专有名词识别率 |
| **说话人** | 声纹注册/管理 |
| **快捷键** | 全局热键配置 |
| **会议输出** | 输出格式（纯文本/含说话人/含摘要/完整） |
| **AI 模型** | LLM 提供者、模型名、摘要间隔、自定义 API |
| **历史** | 搜索、编辑、导出、删除转录记录 |

## API 端点一览

| 端点 | 方法 | 用途 |
|------|------|------|
| `/` | GET | 服务状态 |
| `/health` | GET | 健康检查 |
| `/engines` | GET | 可用引擎列表 |
| `/load` | POST | 预加载引擎/模型 |
| `/transcribe` | POST | 文件转录 |
| `/stream` | WebSocket | 流式转录 |
| `/meeting` | WebSocket | 会议录制（完整流水线） |
| `/models` | GET | 模型列表及状态 |
| `/models/download` | POST | 下载模型 |
| `/models/delete` | POST | 删除模型 |
| `/speakers` | GET | 已注册说话人 |
| `/speakers/register` | POST | 注册声纹 |
| `/speakers/{id}` | DELETE | 删除说话人 |

## 技术栈

| 层 | 技术 |
|----|------|
| 桌面框架 | Electron + Next.js |
| UI | React + Tailwind CSS + Radix UI |
| 状态管理 | Zustand (持久化) |
| 后端 | Python FastAPI + Uvicorn |
| ASR | faster-whisper / FunASR / FireRedASR / NeMo / whisper.cpp |
| 说话人 | pyannote.audio + diart + CAM++ |
| VAD | Silero VAD |
| AI | Claude CLI / Anthropic SDK |
| 音频 | 16kHz 单声道 PCM/WAV |
