# VoiceScribe 前端文档

更新时间：2026-03-15  
核心目录：`frontend/src`、`frontend/electron`

## 1. 前端架构

- UI：React + Next.js
- 桌面壳：Electron
- 状态管理：Zustand
- Renderer <-> Main：Electron IPC
- Main <-> Backend：HTTP + WebSocket

## 2. 页面与主入口

### 2.1 页面入口

- `frontend/src/app/page.tsx`
- `frontend/src/app/overlay/page.tsx`

### 2.2 主要状态入口

- `GlobalRecordingManager.tsx`
- `recording-store.ts`
- `stream-websocket.ts`

当前主 UI 已接入稳定的流式转录入口，不再是“后端有 `/stream`、前端未接线”的旧状态。

## 3. 设置页结构

当前设置标签包括：
- `live-transcript`
- `general`
- `engine`
- `vocabulary`
- `speaker`
- `hotkey`
- `history`

关键能力：
- 引擎与模型切换
- 流式转录开关
- 说话人识别开关
- speaker model 选择
- 热词配置
- 历史导出配置

## 4. 流式录音链路

### 4.1 Renderer 侧

- 采集 PCM 音频
- 通过 `StreamWebSocket` 连接 `WS /stream`
- 接收 `started / utterance / utterance_refined / speaker_active / summary / session_end`

### 4.2 Store 侧

`recording-store.ts` 当前已支持：
- `currentUtterances`
- `currentSummary`
- `activeSpeaker`
- `activeSpeakers`
- `history`

`Utterance` 当前结构支持：
- `speaker`
- `speakerId`
- `speakers`
- `overlapDetected`
- `overlapScore`
- `speakerSpans`

这意味着前端已经支持显示：
- 多 speaker labels
- overlap 标记
- `speaker_spans`

## 5. Speaker 与模型联动

当前前端在三个时机会触发 speaker backend 重载：

1. 设置变更时  
- `enableStreaming`
- `enableDiarization`
- `speakerModel`

2. 引擎页点击“加载模型”时  
- 若流式或说话人识别开启，会额外调用 `/speakers/reload-models`

3. 应用启动后  
- 会同步当前设置到后端 speaker backends

## 6. 历史与导出

当前历史记录存储在 `voicescribe-recordings`。  
支持：
- 编辑
- 删除
- speaker 过滤
- 导出 TXT / Markdown

导出层已经支持：
- 多 speaker 标签拼接
- overlap 标记
- 流式 utterances 和摘要输出

## 7. 当前前端边界

- UI 已能表达“一个 utterance 对应多个 speaker labels”
- UI 也能展示 `speaker_spans`
- 但还没有做“同一时间点多人同时说话”的复杂时间轴视图
