# VoiceScribe 前端文档

更新时间：2026-02-23  
核心目录：`frontend/src`、`frontend/electron`

## 1. 前端架构
- UI 层：Next.js + React（`frontend/src/app`）
- 桌面壳：Electron（`frontend/electron`）
- 状态管理：Zustand（历史记录）
- 通信：
- Renderer <-> Main：Electron IPC
- Main <-> Backend：HTTP（`frontend/electron/backend.ts`）

## 2. 页面与组件
### 2.1 页面入口
- `frontend/src/app/page.tsx`
- 渲染 `SettingsPanel`
- 挂载 `GlobalRecordingManager` 负责录音 IPC 事件与结果入库

- `frontend/src/app/overlay/page.tsx`
- 录音悬浮页，监听 `recording-state` 更新状态

### 2.2 设置面板
文件：`frontend/src/components/settings/SettingsPanel.tsx`  
当前标签页：
- `general` 通用设置
- `engine` 引擎设置
- `vocabulary` 词表设置
- `speaker` 说话人设置
- `hotkey` 快捷键设置
- `history` 历史记录

### 2.3 关键功能组件
- `GlobalRecordingManager.tsx`
- 监听 `start-audio-recording` / `stop-audio-recording` / `cancel-audio-recording`
- 调用录音器生成 WAV
- 调用 `window.electron.recording.transcribeAudio(...)`
- 接收 `transcription-complete` 事件并写入历史

- `RecordingOverlay.tsx`
- 展示录音、思考、取消等状态动画

## 3. 录音与音频处理
- `frontend/src/lib/wav-recorder.ts`
- 通过 WebAudio 采集 PCM
- 下采样并编码为 WAV（16kHz，mono，PCM16）
- 提供实时音量 `getAudioLevel()`

- `frontend/src/lib/audio-recorder.ts`
- 对 `WavRecorder` 的轻量封装
- 提供全局单例

## 4. 状态管理
文件：`frontend/src/store/app-store.ts`
- `transcriptions`：转写历史数组
- 提供：
- `addTranscription`
- `updateTranscription`
- `deleteTranscription`
- `clearHistory`
- 持久化键：`voicescribe-storage`（localStorage）

## 5. Electron 主进程（前端侧关键）
文件：`frontend/electron/main.ts`
- 创建主窗口与 overlay 窗口
- 托盘菜单与快捷键注册
- 录音状态机：`isRecording` / `isTranscribing` / `cancelled`
- IPC handlers：
- 录音控制：`toggle-recording`、`cancel-recording`
- 设置：`get-settings`、`update-settings`
- 热键：`get-hotkey`、`update-hotkey`
- 后端：`check-backend`、`get-engines`、`load-engine`、`get-models` 等
- 转写：`transcribe-audio`

## 6. 预加载桥接 API
文件：`frontend/electron/preload.ts`
- 暴露 `window.electron`：
- `recording`
- `hotkey`
- `backend`
- `settings`
- `window`
- `app`
- `transcription`

类型声明：
- `frontend/src/types/electron.d.ts`

## 7. 与后端通信
文件：`frontend/electron/backend.ts`
- 统一 HTTP 请求封装（支持 JSON/FormData、超时）
- 主要方法：
- `checkHealth`
- `getEngines`
- `loadEngine`
- `transcribe`
- `getSpeakers` / `registerSpeaker` / `deleteSpeaker`
- `getModels` / `downloadModel` / `deleteModel`

## 8. 构建与开发
`frontend/package.json` 关键脚本：
- `npm run dev`：Next.js 开发
- `npm run build`：Next.js 构建
- `npm run build:electron`：编译 Electron TS
- `npm run dev:electron`：并行启动 Next + Electron
- `npm run package`：打包安装程序
