## 启动步骤

### 方法 1: 使用 dev.bat 脚本（推荐）

```bash
cd scripts/windows
.\dev.bat
```

这个脚本会：
1. 检查前置条件（conda, Node.js）
2. 启动后端服务（新窗口）
3. 等待后端就绪
4. 启动 Electron 前端

### 方法 2: 手动启动

#### 1. 启动后端
```bash
cd backend
conda activate voicescribe
python server.py
```

#### 2. 启动前端（新终端）
```bash
cd frontend
npm run dev:electron
```

## 常见问题排查

### 问题 1: 端口 3000 被占用
```bash
# 查找占用端口的进程
netstat -ano | findstr :3000

# 停止进程（替换 <PID> 为实际进程 ID）
taskkill /F /PID <PID>
```

### 问题 2: 后端未连接
```bash
# 检查后端是否运行
curl http://127.0.0.1:8765/health

# 或在浏览器打开
http://127.0.0.1:8765
```

### 问题 3: 快捷键不工作
- 检查是否有其他应用占用了相同的快捷键
- 尝试更换快捷键组合
- 重启应用

### 问题 4: 录音没有声音
- 检查麦克风权限
- 检查系统音量设置
- 在浏览器中测试麦克风（chrome://settings/content/microphone）

### 问题 5: 转录失败
- 检查后端日志（backend/server_out.log 和 server_err.log）
- 检查模型是否正确加载
- 尝试重新加载模型

### 问题 6: GPU 缓存错误（可忽略）
```
ERROR:net\disk_cache\cache_util_win.cc:25] Unable to move the cache
```
这是 Electron 的已知问题，不影响功能，可以忽略。

## 性能优化建议

1. **首次使用**：首次加载模型会自动下载，FunASR 模型约 1-2GB，请耐心等待
2. **预加载模型**：在"引擎设置"中预加载常用模型，可以加快首次转录速度
3. **选择合适的模型**：
   - 速度优先：whisper tiny/base
   - 平衡：whisper medium, funasr seaco-paraformer
   - 准确率优先：whisper large-v3
4. **热词功能**：添加常用专有名词到"词汇设置"，可以提高识别准确率
