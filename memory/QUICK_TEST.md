## 🔍 立即测试

### 1. 检查界面是否正常显示

打开的 Electron 窗口应该显示：
- 左侧导航栏：通用、引擎、词汇、说话人、快捷键、历史记录

### 2. 测试录音功能

#### 步骤：
1. **按住 Alt+B** 键（不要松开）
2. **对着麦克风说话**："这是一个测试"
3. **松开 Alt+B** 键

#### 预期结果：
- ✅ 按住时：应该看到一个小窗口出现，显示音波动画
- ✅ 松开后：窗口显示"转录中..."（至少 1 秒）
- ✅ 转录完成：窗口自动关闭
- ✅ 结果：文本自动复制到剪贴板

#### 验证：
- 打开记事本
- 按 Ctrl+V 粘贴
- 应该看到转录的文本

### 3. 检查历史记录

1. 在应用中点击"历史记录"
2. 应该看到刚才的转录记录
3. 点击记录可以查看详情

## ⚠️ 如果录音不工作

### 问题 1: 没有看到录音窗口

**可能原因**：
- 快捷键冲突
- 麦克风权限未授予

**解决方法**：
1. 打开"快捷键设置"
2. 更换快捷键（例如：Alt+R）
3. 点击"应用快捷键"
4. 重新测试

### 问题 2: 录音窗口出现但没有音波动画

**可能原因**：
- 麦克风未选择正确
- 麦克风权限被拒绝

**解决方法**：
1. 检查 Windows 设置 → 隐私 → 麦克风
2. 确保允许应用访问麦克风
3. 在浏览器中测试麦克风：chrome://settings/content/microphone

### 问题 3: 转录失败或显示"[转录失败]"

**可能原因**：
- 后端未连接
- 模型未加载

**解决方法**：
1. 打开"通用设置"
2. 检查"后端状态"是否为"已连接"
3. 如果未连接，检查后端窗口是否在运行
4. 打开"引擎设置"
5. 点击"加载模型"按钮
6. 等待模型加载完成

### 问题 4: 转录结果不准确

**解决方法**：
1. 打开"词汇设置"
2. 添加常用的专有名词
3. 打开"引擎设置"
4. 尝试更换引擎或模型：
   - 中文：FunASR seaco-paraformer（推荐）
   - 英文：Whisper medium 或 large-v3
5. 说话时尽量清晰、语速适中

## 🔧 调试技巧

### 1. 查看完整的启动日志
```bash
cd frontend
npm run dev:electron
```

### 2. 单独启动后端查看详细日志
```bash
cd backend
conda activate voicescribe
python server.py
```

### 3. 测试后端 API
```bash
# 在浏览器中打开
http://127.0.0.1:8765

# 或使用 curl
curl http://127.0.0.1:8765/health
```

### 4. 查看 Electron 主进程日志
在 Electron 窗口的控制台中，查找以下关键字：
- `[Recording]` - 录音相关
- `[Transcribe]` - 转录相关
- `[Output]` - 输出相关
- `[Backend]` - 后端通信相关
