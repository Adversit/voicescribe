## 技术笔记

### whisper.cpp 使用

```bash
# 安装
brew install whisper-cpp

# 下载模型（用国内镜像）
mkdir -p ~/.whisper-models
curl -L -o ~/.whisper-models/ggml-base.bin "https://hf-mirror.com/ggerganov/whisper.cpp/resolve/main/ggml-base.bin"

# 转录
/opt/homebrew/bin/whisper-cli -m ~/.whisper-models/ggml-base.bin -f audio.wav -l zh
```

### 运行方式

```bash
cd ~/clawd/projects/voicescribe/backend
source venv/bin/activate
python server.py  # 自动检测可用引擎
```
