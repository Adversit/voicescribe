## 1. 录音功能测试

### 基本录音流程
1. **开始录音**：按 `Alt+R` 快捷键
   - 预期：屏幕底部中央出现录音窗口
   - 显示：录音指示灯（白色圆点闪烁）+ 音波动画 + 时长计时

2. **停止录音**：再次按 `Alt+R` 快捷键
   - 预期：显示 "thinking" 动画（转录中）
   - 转录完成后窗口自动隐藏

3. **取消录音**：鼠标悬停在录音窗口上，点击
   - 预期：窗口变红色，显示"点击取消"
   - 点击后显示"已取消"，1秒后窗口消失

### 录音窗口交互
- **拖动窗口**：直接拖动窗口到任意位置（不要悬停）
- **取消录音**：悬停后点击（窗口变红色）
- **查看时长**：窗口显示录音时长（格式：MM:SS）

## 2. 输出模式测试

### 测试前准备
打开"设置" → "通用" → "输出方式"

### 模式 1: 复制到剪贴板
1. 选择"复制到剪贴板"
2. 按 `Alt+R` 开始录音
3. 说话："这是一个测试"
4. 按 `Alt+R` 停止录音
5. **验证**：打开记事本，按 `Ctrl+V` 粘贴
   - ✅ 应该能看到转录的文本

### 模式 2: 直接输入到应用
1. 选择"直接输入到应用"
2. 打开记事本（或任何文本编辑器）
3. 确保记事本窗口处于焦点状态
4. 按 `Alt+R` 开始录音
5. 说话："自动输入测试"
6. 按 `Alt+R` 停止录音
7. **验证**：文本应该自动出现在记事本中
   - ✅ 使用 PowerShell SendKeys 自动粘贴
   - ⚠️ 如果失败，文本在剪贴板中，手动 `Ctrl+V` 粘贴

### 模式 3: 两者都执行
1. 选择"两者都执行"
2. 行为与"直接输入到应用"相同
3. 文本会自动粘贴到当前应用

## 4. 说话人识别测试

### 启用说话人识别
1. 设置 → 通用 → 启用说话人识别 → 打开开关
2. 录音（多人对话场景）

3. 再次录音
4. **验证**：转录结果中显示注册的姓名而不是 Speaker 1

## 常见问题排查

### 问题 1: 录音窗口不显示
**检查：**
- 快捷键是否正确注册
- 查看控制台日志
- 重启应用

### 问题 2: 转录失败
**检查：**
- 后端服务是否运行（http://127.0.0.1:8765/health）
- 模型是否加载
- 音频文件格式是否支持

### 问题 3: 自动粘贴不工作
**检查：**
- 输出模式是否设置为"直接输入到应用"
- 目标应用是否有焦点
- 查看控制台日志（PowerShell 方法是否成功）
- 备选方案：手动 Ctrl+V 粘贴

### 问题 4: 端口占用
**解决：**
```powershell
netstat -ano | findstr :3000
taskkill /F /PID <进程ID>
```

## 性能测试

### 转录速度
- 短音频（<10秒）：应在 2-3 秒内完成
- 中等音频（10-60秒）：应在 5-10 秒内完成
- 长音频（>60秒）：根据音频长度线性增长

### 内存使用
- 空闲状态：< 200MB
- 录音状态：< 300MB
- 转录状态：< 500MB（取决于模型大小）

### CPU 使用
- 空闲状态：< 5%
- 录音状态：< 10%
- 转录状态：根据硬件配置（GPU 加速时 CPU 使用率低）
